# 设备与恢复条件

[English](equipment.md)

## 首次安装需要

| 设备 | 用途 |
| --- | --- |
| 匹配的 L75MA-SPL / freeguy 电视 | 本项目只在这一块主板上验证过，还必须核对固件、启动链和镜像哈希，不能只看商品型号。 |
| 有足够空间的电脑 | 构建镜像、保留原文件，并在电视之外存放已校验的备份。日常启动完成适配后不依赖电脑。 |
| 与主板兼容的小米／MTK HDMI 转 UART USB 调试线，通常称为“HDMI 转 TTL” | 读取早期日志、截停 Bootloader，在 Android 无法启动时撤销已支持的启动配置变更。 |
| 保存在电视之外并经过校验的备份 | Android 无法启动时，仍能取得原始启动配置及所需的固件、数据备份。只存在电视内的文件不算独立备份。 |
| 连接可信局域网的网线 | Android 运行时传输与检查文件，不能替代早期启动恢复连接。 |
| 电视遥控器和可操作的电源 | 操作界面，必要时按明确步骤断电恢复。 |
| 稳定供电 | 配置或文件系统写入时断电，仍可能留下无法启动的状态。 |

这些是首次安装和故障恢复的准备条件。安装并验证后，日常切换使用电视内部存储，
不要求连接电脑、串口线或 U 盘；请保留调试线和备份，以备恢复时使用。

磁盘应能同时容纳两套完整镜像、展开的构建文件及独立备份，构建前按实际大小核算。
U 盘可以用于转移备份，不需要长期插在电视上；电脑空间不足时可用外置盘保存备份。

本机使用 **HDMI 1、115200 波特率、8N1**。
普通 HDMI 线、采集卡、USB 视频转接器都不能替代串口调试线。
向供应商确认针脚和电气兼容性，不要凭接口外形猜线序或电压，
也不要向电视接入外部供电引脚。
电脑必须能将调试线识别为串口设备；商品标注“HDMI 转 TTL”本身不能证明兼容本机主板。

改启动配置之前，必须验证：能读启动日志、能输入并进入 Bootloader 控制台、
能实际执行精确撤销并正常启动。只收到文字不能证明发送通路可用。

## 没有 HDMI 串口怎么办

可以先阅读代码、下载官方输入并离线构建。本项目的安装流程要求先有经过验证的
串口恢复通路，再修改启动配置。
如果没有这条通路，请停留在离线准备阶段，不要修改电视的启动配置。

ADB 依赖 Android 正常运行。Fastboot 和 Recovery 菜单在这台电视上不保证提供
可用的回写入口；有 USB 线、U 盘或者 A/B 两个槽位，也不等于能恢复。
此前事故中，清除数据和尝试 U 盘入口均没有解决循环启动，最终通过串口恢复。

缺少串口仍继续操作，可能只能寻找匹配的售后恢复包、进行主板级维修或更换主板。
有串口也不代表所有故障都能修复，它本身不能恢复物理损坏或已经无法运行的 Bootloader。

## 按需准备

- HDMI 信号源：验证画面、声音、刷新率切换和返回桌面。
- 支持 CEC 的盒子或游戏机：验证设备名和遥控器联动。
- U 盘、蓝牙音箱、ARC/eARC 设备：需要这些功能再测试，否则记录为未验证。
- 对准屏幕的摄像头：用于无人值守观察。系统截图不能证明实体面板已经亮起。
